# P5B 本地账号与按账号保存的对话历史

- 阶段：Program Phase II / P5B 平台共性补齐
- 状态：已获项目负责人批准；等待实现任务协议
- 前置 ADR：[ADR-0004 本地账号、会话与对话历史的持久化边界](../adr/0004-local-account-and-conversation-history.md)
- 数据等级：首期仅 L0 Fixture 与 L1 Synthetic Scenario

## 用户价值

维护人员使用本地账号登录后，可以在自己的账号下看到、继续和删除历史对话。历史不是前端伪造列表；每次读取和继续追问都仍受当前服务端角色、项目和 Scope 约束。

## 范围

- 本地账号注册/受控创建、登录、注销、服务端会话与本地密码哈希存储。
- 账号到角色、项目 Scope 的服务端绑定；现有开发常量身份仅作为测试/Fixture 迁移支持。
- 按账号、项目和创建时间保存对话、消息、已验证展示指令元数据与最小数据来源/限制标签。
- 最近对话列表、重新打开会话、继续追问、单会话删除和账号删除时的会话清理。
- 本地数据库迁移、启动失败关闭、最小备份/恢复边界和安全测试。

## 非目标

- 不接入 SSO、LDAP、OAuth、企业身份源、外部网络或多实例账号同步。
- 不保存真实 Zabbix 数据、真实原始指标、模型 Provider 输入输出、密码明文、Token 或真实客户数据。
- 不改写 P4 无状态 Standalone 的历史验收结论；持久化 Profile 必须作为新能力单独验收。
- 不增加写型运维业务能力。账号、会话和用户主动删除只属于平台身份/数据治理，不授予设备或工单写权限。

## 依赖

- [ADR-0004](../adr/0004-local-account-and-conversation-history.md)。
- P1 `Scope`、`AuditEvent`、`PlatformResponse` 和拒绝语义；历史读取必须重新应用当前 Scope。
- P5A 的展示指令只存储已验证的元数据和会话引用；重新打开时必须重新验证、重新查询，不能把历史结果作为当前事实返回。
- 公开仓库敏感信息限制、严格只读和 Fixture/Scenario-first 流程。

## 实施顺序

1. 冻结本地账号、会话、对话、删除和身份提供者抽象的版本化接口与迁移计划。
2. 实现服务端本地身份、会话与数据库迁移，再替换前端开发身份假设。
3. 完成按账号历史与删除流程，随后接入 P5A 最近对话界面。
4. 在独立 Capability 中评估 SSO；不得把本地账号数据模型直接绑定到某个外部厂商。

## 验收

- 密码明文、Token、数据库文件和会话内容不进入 Git、错误日志、fixture 或测试报告；密码校验与会话失效均失败关闭。
- 账号 A 不能枚举、读取、继续或删除账号 B 的会话；项目/角色 Scope 收窄后，重新打开历史不返回越权结果或历史数据快照。
- 用户可删除自己的对话；删除后列表、详情和后续读取均不可恢复。账号删除按已批准的级联规则清理其会话正文。
- 刷新和重新登录后，最近对话按当前账号恢复；当前无状态 Fixture Demo 的现有 API 行为在兼容路径上仍可回归。
- 数据库迁移、损坏、不可写、会话过期和权限拒绝都有明确的安全错误路径。
- 独立 Test Agent 完成身份、权限、删除、迁移、回归和无敏感信息泄露的验收；真实数据/SSO/Production 均明确为未测且不在范围内。

## 风险

- 本地账号和持久化扩大了攻击面与运维责任；实现前必须完成目录范围、迁移/备份方案、密码库选择和安全评审。
- 对话未来可能包含敏感运维信息。真实数据或模型 Provider 加入前必须另行决定存储、脱敏、保留、导出和密钥管理。
- 当前集中式 API 与固定开发身份会产生集成冲突；身份/数据库/API 变更由 Project Lead 串行协调，前端历史列表可在接口冻结后并行。
