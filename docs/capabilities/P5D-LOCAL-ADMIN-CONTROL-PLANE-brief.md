# P5D 本地后台管理控制面

- 阶段：Program Phase II / P5D 平台管理面
- 前置 ADR：[ADR-0005](../adr/0005-local-admin-control-plane.md)
- 数据等级：仅 L0 Fixture 与 L1 Synthetic Scenario 的控制面元数据

## 用户价值

项目管理员可在一个与前台视觉一致、但职责明确分离的后台中查看真实能力状态、管理本地账号、审计控制面操作，并安全停止或恢复已注册的业务能力。前台继续只承担自然语言查询与 Work Mode 展示。

## 范围

- `/admin` 本地管理员入口、概览、能力管理、账号管理、审计日志和只读系统状态。
- 本机交互式首位 `project-admin` 初始化；没有默认凭据。
- 本地 SQLite 持久化审计、账号启停/会话撤销与业务 Capability 启停。
- 已停用 Capability 的服务端失败关闭；不改变既有 Scope、Tool、ViewContext 或严格只读语义。

## 非目标

- 不接入 SSO、LDAP、外部身份、真实 Provider、真实 Zabbix、真实数据或远程控制面。
- 不在后台配置任意 Scope、角色、Tool、View、Connector、环境变量或凭据。
- 不伪造调用趋势、健康趋势、知识库、模型、工单或发布流水线。
- 不在后台读取或导出其他账号的对话正文。

## 依赖

- P1 `Scope -> Tool -> ViewContext -> Workspace` 与严格只读规则。
- P5B 本地账号和 SQLite 持久化边界。
- 注册表中的 Capability Manifest；后续配置必须以版本化 Schema 注册。

## 验收

- 未登录、普通账号、已停用账号均不能读取或改变 `/v1/admin/*`。
- 业务 Capability 被停用后，其查询/聊天路径返回安全的结构化拒绝；重新启用后可按原 Scope 正常运行。
- 审计跨 API 进程重启可读取，且不包含密码、Token 或对话正文。
- 管理员不能停用平台基础能力、提升账号 Scope 或写入未注册配置。
- 浏览器验证 `/admin` 的登录拒绝、概览、能力启停、账号停用/会话撤销、审计筛选与窄屏可用性；既有前台与 API 回归继续通过。

## 风险

- 本地控制面扩大了 SQLite 的治理责任；数据库仍必须位于忽略目录并由本机文件权限保护。
- 停用能力可能让前台请求失败，因此前端必须呈现明确、非误导性的拒绝状态。
- 首位管理员初始化是本机运维动作；丢失密码不能通过仓库或默认后门恢复。
